# 🎮 Genius com Arduino

## 📌 Sobre o projeto

Este projeto tem como objetivo desenvolver uma versão do jogo **Genius** utilizando Arduino, reproduzindo sua dinâmica de memorização de sequências de cores e sons.

O jogador deverá observar a sequência apresentada pelo dispositivo e repeti-la corretamente. A cada rodada, a sequência aumenta, tornando o desafio progressivamente mais difícil.

## 📁 Organização do repositório

Neste repositório serão disponibilizadas as diferentes versões desenvolvidas ao longo do projeto, permitindo acompanhar sua evolução e as modificações realizadas durante a implementação.

Após a finalização, também será adicionada uma documentação contendo:

- Passo a passo de montagem do projeto;
- Explicação dos componentes utilizados;
- Descrição do funcionamento do circuito;
- Explicação do código e de suas principais funções.

## 🛠️ Tecnologias utilizadas

- Arduino
- C/C++
- Wokwi (simulação e testes)
